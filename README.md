📊 Misuo Company Dashboard | Microsoft Excel
📌 Project Overview

This project involved conducting a complete data analysis for Misuo Company using Microsoft Excel. The dataset required extensive cleaning and validation due to multiple data entry issues and inconsistencies.

The goal was to transform raw, unstructured data into meaningful insights through an interactive dashboard and a business-focused report.
